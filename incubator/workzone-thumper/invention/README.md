# WorkZone Thumper — Invention Record

This folder preserves technical evolution for engineering continuity, diligence, and potential future patent work.

It is not a substitute for a patent filing or legal advice.

## Rules
- Preserve original ideas and versions; never overwrite history.
- Add dated entries for each material change.
- Preserve sketches, simulations, test setups, audio/acoustic parameters, electronics changes, radar logic, measurements, video, and field observations.
- Record contributors and the exact conceptual contribution.
- Record demonstrations, offers for sale, publications, public tests, presentations, or other disclosures.
- Link entries to Git commits/tags when possible.
- Separate hypothesis from measured result.
