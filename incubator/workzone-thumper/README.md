# WorkZone Thumper

WorkZone Thumper is a portable roadside work-zone warning system intended to create a rumble-strip-like tactile/in-cabin warning for approaching drivers without physically modifying the roadway.

Earlier working names:
- Virtual Rumble Strip
- Active Rumble Zone

## Current concept
Radar or other detection estimates speed / closing behavior, a controller determines warning severity, and a low-frequency transducer/amplifier produces a directional pulse pattern intended to be perceived inside the approaching vehicle.

## Current stage
Explore / prototype definition.

## Immediate objective
Build and validate a manual V0 acoustic/tactile prototype before adding automated radar triggering.
