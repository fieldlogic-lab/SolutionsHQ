# Hydrographic USV — Invention Watch Record

Hydrographic USV is currently a **patent-watch** project rather than a presumed patent candidate.

Much of the platform may use known components and standard autonomy/GNSS practices. This record exists to capture only genuinely novel system architecture that emerges during development.

## Record when novel
Create an invention entry if the project develops a distinct:
- hull or propulsion configuration;
- sensor-mounting / stabilization arrangement;
- deployment/recovery mechanism;
- GNSS / hydrographic integration method;
- safety/control architecture;
- shallow-water operating mechanism;
- automated survey workflow tightly coupled to the physical platform.

Do not create “inventive” records for routine configuration of known off-the-shelf hardware.
