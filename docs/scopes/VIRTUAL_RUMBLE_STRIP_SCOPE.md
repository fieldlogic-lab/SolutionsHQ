# Virtual Rumble Strip / Active Rumble Zone — Project Scope

## Purpose
Create a rapidly deployable work-zone warning system that makes approaching drivers perceive a rumble-strip-like tactile/in-cabin warning without installing a physical roadway rumble strip.

## Existing architecture
Radar detects speed/closing behavior → controller → low-frequency amplifier/transducer → directional low-frequency pulses. Pulse cadence/number changes with risk.

## Product path
- V0 manual acoustic/tactile prototype;
- validate 75–150 ft in-cabin perception and worker/external exposure;
- V2 radar-triggered warning;
- later portable/networked Pod, Cone, or Zone product family.

## Intended use
Utility, surveying, paving, tree, emergency, contractor, and DOT roadside work zones, particularly local/non-highway operations.

## Proposed repository
`fieldlogic-lab/Virtual-Rumble-Strip`

## Next step
Build the V0 prototype, define measurable perception/exposure criteria, and run controlled vehicle tests before adding radar triggering.
