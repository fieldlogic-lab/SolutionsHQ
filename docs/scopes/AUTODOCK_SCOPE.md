# AutoDock — Project Scope

## Purpose
Create a self-centering berth/slip system that aligns and automatically captures a recreational boat during single-handed docking.

## Existing architecture
- passive dock-mounted funnel;
- soft guides/rollers;
- dedicated boat-side receiver;
- automatic capture/latch;
- opposing counterweighted lines for centering/slack control;
- floating-dock or vertical tide-travel accommodation.

## Prototype path
Build a 1:10 slip and Pursuit-shaped hull, test deliberately poor approach angles, refine funnel/latch geometry, then scale to full-size fabrication.

## Intended user
Recreational boaters docking with limited crew, especially where wind/tide make slip alignment and line handling difficult.

## Proposed repository
`fieldlogic-lab/AutoDock`

## Next step
Create the scale CAD/prototype and define measurable success/failure criteria for alignment, capture, release, tide travel, and fail-safe behavior.
