# Coxswain Navigation System — Project Scope

## Purpose
Create an on-water rowing navigation and workout execution system for coxswains using a phone-mounted, GPS-aware interface.

## Current state
The concept includes a split workout/map view, mapped buoys and lanes, distance and split tracking, battery-awareness, and a no-touch-during-practice operating principle.

## Near-term objective
Build a simple field prototype that can guide one full Port Jefferson Harbor practice without requiring interaction once underway.

## In scope
Mobile runtime, GPS, mapped rowing geometry, workout display, distance/split calculations, route recording, screen/battery behavior, phone-holder hardware, field testing, and a clean data boundary with SBU Crew Coach.

## Boundary
SBU Crew Coach remains the coaching operations and training-plan system. Coxswain Navigation owns the on-water execution/navigation experience.

## Proposed authoritative repository
`fieldlogic-lab/Coxswain-Navigation`

## Next step
Define v0.1 field requirements and build the map/workout prototype plus physical phone-holder test.
