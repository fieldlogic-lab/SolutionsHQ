## Promotion rule
A concept graduates to the main Solutions HQ project listing when it has:
1. a distinct purpose and user/customer;
2. independent decisions, design, architecture, or product requirements;
3. more than one meaningful work session **or** a concrete committed prototype/build path;
4. a durable next step;
5. enough unique history that losing its context would materially slow re-entry.

Graduated projects should receive:
- an authoritative repository or explicit source-of-truth location;
- a project scope;
- decision log;
- implementation/current-status record;
- validation or next-step plan appropriate to the project.
